# Riskfate

**Riskfate** — проєкт безплатної фентезійної MMORPG, яку планується поступово розробляти на **Godot**. У центрі задуму — небезпечний світ, свобода розвитку персонажа, майстерність зброї, матеріальні навики та довгостроковий прогрес.

Проєкт перебуває на етапі обговорення концепції й планування. Частину ігрових, архітектурних і графічних принципів уже погоджено; остаточні технічні параметри та склад першої ігрової версії ще не затверджені.
